Budget Planner AI

This platform is going to host a page,
where user can get the full breakdown of
the trip budget of the city they want to visit.
It is going to do this work by using LLM which
will be connected to MCP by which they are able
to fetch the information about flight and hotels
and will able to breakdown the whole trip budget.

Technologies will be use

Id Category Technologies
1 FrontEnd HTML, CSS, JavaScript, React
2 BackEnd Python (Flask or django)
3 DataBase PostgreSQL
4 LLM Google Gemini, Groq Models

This project approach

  1. Choose the LLM
  2. Connect the LLM with MCP
  3. Create the backend of the Website
  4. Create the FrontEnd of the Website
